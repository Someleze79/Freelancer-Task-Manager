# 🚀 Freelancer Pro

A modern full-stack MERN productivity platform for freelancers and teams to manage projects, tasks, collaboration, real-time chat, notifications, and AI-powered insights.

## 🚀 Installation & Setup

### 1️⃣ Clone Repository

git clone https://github.com/Someleze79/Freelancer-Task-Manager.git

cd Freelancer-Task-Manager

---

### 🔧 Backend Setup

- cd backend

- npm install

- npm run dev

Backend runs on:

http://localhost:5000

---

### 💻 Frontend Setup

- cd freelancer-frontend

- npm install

- npm run dev

Frontend runs on:

http://localhost:5173
